# Logs

One dated file per session. The full engineering story lives here.

---

## Rules

- One file per session, named `YYYY-MM-DD.md`
- Every action is logged immediately - not batched at the end of the session
- If context runs out mid-session, this folder is the source of truth for resuming
- Format: what was done, why, which files changed, what is next
- Every agent updates the current session file when it finishes a task
