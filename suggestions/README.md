# Suggestions

A living backlog of improvements and ideas for PHAEMOS.

Each suggestion is its own file. When a suggestion is implemented, delete the file. Review this folder at the start of every session.

---

## Format

Every suggestion file follows this structure:

```
# [Title]

**Why it matters:** one sentence.

**Rough approach:** what would need to change.

**Priority:** high / medium / low
```
